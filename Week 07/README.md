# Week 7 — the dashboard (Parts A–E; bonus F not attempted)

Run from this folder, in this order:
1. `python3 partA_process.py` — audit, clean, decisions table → `clean/`, `partA_audit.txt`, `partA_decisions.md`.
2. `python3 partB_charts.py` — `partB_1.png` … `partB_4.png`.
3. `python3 partC_interactive.py` — `partC_interactive.html` (live, Plotly) and `partC_default.png`. Contract: `partC_contract.md`.
4. `python3 partD_screen.py` — `partD_screen.png` (300 dpi) and `partD_audit.txt` (channel_conflicts, cvd_report).

`partE_note.md` is the note (window choice, parameters, counterfactual, ethics clause).
Toolkits `vizlib.py`, `tslib.py`, `geolib.py`, `dashlib.py` are the course versions, unchanged, except that `dashlib` is the course file as shipped.
Raw data in `data/` is never written to.
