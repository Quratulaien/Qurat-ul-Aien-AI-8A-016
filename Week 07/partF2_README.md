# Task F2 — five readers, twenty seconds each

Show each of five real readers the static PNG of the Task D screen (partD_screen.png) for 20 seconds, then ask them: "In one sentence, what is this showing?"

Record one row per reader in partF2_takeaways.csv:
- reader_id: anonymous (R1 … R5)
- seconds_shown: 20
- one_sentence_takeaway: their words, unedited
- read_correctly_yes_no: compare with the intended takeaway in partD_screen.png's headline; fill this in yourself after reading each sentence
- what_i_would_change: the change you would make after this reader's answer

This file is empty on purpose. It stays empty until real readers have seen the screen.
